# Assignment 1 - Pyramids everywhere

This assignment introduces basic Python, NumPy, Matplotlib, and OpenCV concepts.  
It includes three small exercises:

1. **Pyramid Case (Python):** alternating upper/lower letters in a string.  
2. **Build Pyramid (NumPy & Matplotlib):** plotting pyramid shapes using arrays.  
3. **Forest Pyramid (OpenCV):** combining two grayscale images with masking.

These exercises demonstrate fundamentals of programming, debugging, and basic image processing.
